## 🧠 About

I'm an Intelligent Manufacturing undergraduate at **Xi'an Jiaotong University (XJTU)**,
working on embodied intelligence and robotic systems.

I'm particularly interested in **Vision-Language-Action (VLA) models** and **world models**,
and how they can improve robot learning, planning, and sim-to-real deployment.

## 🔬 Current Interests

- Vision-Language-Action (VLA)
- World Models for Robotics
- Robot Learning & Imitation Learning
- Sim2Real Transfer
- ROS 2 and Real-World Robot Systems

## 🚀 Featured Projects

### [UAV–UGV Cooperative System (Sim-to-Real)](https://github.com/jiangmingxuan234-alt/uav-ugv-cooperative-system-sim-to-real)

Air–ground cooperation with state-machine task coordination, perception-driven decisions,
PX4/MAVROS control, RflySim simulation, and real-world validation.

`C++` · `Python` · `ROS` · `PX4` · `RflySim` · `Sim2Real`

### [Embodied-AI-Franka](https://github.com/jiangmingxuan234-alt/Embodied-AI-Franka)

Imitation learning with shared autonomy for a Franka robot in Isaac Sim,
linking learned policies with state-machine-based execution.

`Python` · `PyTorch` · `Isaac Sim` · `Imitation Learning`

### [bxi_controller_ros2](https://github.com/jiangmingxuan234-alt/bxi_controller_ros2)

A unified ROS 2 controller example that supports both MuJoCo simulation
and BXI robot hardware, including learned control and teleoperation interfaces.

`Python` · `ROS 2` · `MuJoCo` · `Reinforcement Learning`
